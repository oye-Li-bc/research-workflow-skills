# Changelog

## 0.1.0 — 2026-10-21

- Initial public rewrite of seven research workflows derived from local Work
  and Hermes use cases, with source lineage and redistribution notes.
- Four standard-library helpers: bounded arXiv extraction, environment metadata,
  notebook presentation boundaries, and read-only wikilink target checks.
- Validation, selective install without overwrite, deterministic packaging,
  checksums, CI, and tag-triggered release workflow.
- Fourteen manual agent-evaluation cases. These cases are not yet executed.

No earlier public releases or external user adoption are claimed.
