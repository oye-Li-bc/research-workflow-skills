# Research Workflow Skills v0.1.0

First release of seven research-workflow skills distilled from local Work and
Hermes customizations. The library covers paper source handling, Beamer planning,
Jupyter diagnosis, notebook slides, Obsidian notes, RL/VLA tutoring, and figures.

The source archive includes independent skill folders, four standard-library
helpers, an installer, validation, offline regression tests, provenance, and
fourteen manual agent-evaluation cases. SHA256SUMS accompanies the archive.

Checks performed by the release workflow: catalog/frontmatter/local-reference
validation, Python syntax, and offline helper regression tests. The tests cover
unsafe archive inputs, notebook code/output preservation, wikilink ambiguity,
non-overwriting installs, and reproducible packaging.

The manual agent cases have not been executed. This release does not establish
automatic loading in every Codex/Hermes version, live arXiv retrieval, compiled
slide layout, or measured productivity gains. No papers, private profiles, logs,
or third-party installed skill collection are redistributed.
